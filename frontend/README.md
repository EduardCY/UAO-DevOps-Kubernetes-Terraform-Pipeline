# Frontend

Aplicación React para gestión de usuarios (CRUD).

## Estructura
```
frontend/
├── src/
│   ├── App.js            # Main component
│   ├── components/       # Reusable components
│   ├── services/         # API calls
│   └── styles/           # CSS/styling
├── public/               # Static assets
├── Dockerfile            # Multi-stage build
└── package.json          # Dependencies
```

## Features
- Listado de usuarios
- Crear nuevo usuario
- Actualizar usuario existente
- Eliminar usuario
- Manejo de errores
- Loading states

## Desarrollo
```bash
npm install
npm start
```
